## Key Findings

### 1. The HPV16 genome is AT-rich

GC content of NC_001526: **36.51%**

This places HPV16 well below the 50% GC content typical of the human genome. AT richness in HPV is not incidental it shapes codon usage in E6 and E7, where rare human codons are preferentially used to suppress oncoprotein expression in normal differentiated cells, limiting oncogenic transformation to cells where viral replication is active.
